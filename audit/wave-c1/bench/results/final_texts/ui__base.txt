I wrote `redesigned/index.html` as one self-contained file with inline CSS/JS and system fonts only. I haven't opened it in a browser or run any checks, so the responsiveness and WCAG compliance below are by construction, not tested.

- **Identity:** a navy "night sky" header and hero with a dashed horizon line and a globe logo mark. Below it are a warm paper background, Georgia serif headings, amber accents, and plan cards with hard offset shadows. All plan names, prices, features, FAQ text, the trial CTA and the subscribe form are kept.
- **Layout and accessibility:** fluid layout for 360–1600px, with the plans in one column on mobile and three from 768px up. It has landmarks, a skip link, a single h1, and a two-tone focus ring. Controls are at least 44px tall, and I picked text colours for AA contrast. The email field has a label, `autocomplete` and validation, and plan icons have alt text. It also respects reduced-motion and forced-colors settings.
- **FAQ and actions:** the FAQ is a set of real buttons using `aria-expanded` and `aria-controls`, so Enter and Space work. The legacy `onclick` handlers did nothing, so the trial, plan, Log in and Subscribe buttons now show a preview message in a live region. The nav links scroll to their sections, but the footer Terms, Privacy and Status links only go back to the top.
